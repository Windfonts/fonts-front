Getting started

概述 引入 CSS（link） @import 在 CSS 中使用 参数说明 选字袋 嵌入页 许可与注意

快速开始

一行 CSS 即可在网页中使用文风字体。生产环境请核对许可与域名白名单。本页对应 next-windfonts /docs/getting-started。

1. 用 <link> 引入

将下列代码放入页面的 <head>。建议先 preconnect 再拉 CSS：

<link rel="preconnect" href="https://app.windfonts.com" crossorigin>
<link rel="stylesheet"
  href="https://app.windfonts.com/api/css?family=wenfeng-systcn&weight=400"
  crossorigin="anonymous">

多字重请分别请求，或在 嵌入页 勾选「包含所有字重变体」批量生成。

2. 用 @import 引入

适合写在已有 CSS 文件顶部（注意 @import 必须在其他规则之前）：

<style>
@import url('https://app.windfonts.com/api/css?family=wenfeng-ibmps&weight=400');
@import url('https://app.windfonts.com/api/css?family=wenfeng-ibmps&weight=700');
</style>

3. 在 CSS 中使用

API 返回的 font-family 一般为 windfonts-*（由 wenfeng- slug 映射）。同时保留系统中文回退：

.title {
  font-family: 'windfonts-systcn', 'wenfeng-systcn',
               'PingFang SC', 'Microsoft YaHei', serif;
  font-weight: 400;
  font-style: normal;
}

.hero {
  font-family: 'windfonts-ibmps', 'wenfeng-ibmps', system-ui, sans-serif;
  font-weight: 700;
}

4. 参数说明

  1. family — 字体族 slug，如 wenfeng-systcn、wenfeng-ibmps（见字体详情页）
  2. weight — 字重数字（400、700）或名称映射后的数值；变体以详情页「可选样式」为准

完整 URL 形如：

https://app.windfonts.com/api/css?family={family}&weight={weight}

5. 选字袋工作流

  1. 在 字体库 将字体「加入选择」
  2. 打开 已获取字体 统一预览、移除或跳转嵌入
  3. 选字袋数据存在浏览器 localStorage（键 wf-proto-picks），仅本机原型有效

6. 嵌入页

详情页「获取嵌入代码」进入 font-embed.html?id=…：

  • 当前字体会默认勾选且不可取消
  • 可将选字袋中的其它字体一并勾选
  • 切换 link / @import 标签，一键复制；下方附 CSS 使用示例
// 从详情进入
font-detail.html?id={uuid}
  → 获取嵌入代码
  → font-embed.html?id={uuid}

7. 许可与注意

  • 保留文风许可注释与 wenfeng.org/license 标注
  • CSS API 可能限流（429）；生产应走 CDN / 白名单域名
  • 本原型为静态镜像：无登录、无真实 OSS 下载、无后台写库
