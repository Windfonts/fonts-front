接入文风字体

一行 CSS 就能在网页中使用中文字体。公开字体走 cn.windfonts.com CDN，按字体族与字重取 CSS；正式站点建议创建项目、绑定域名白名单，并核对每款字体的授权范围。

1在字体库挑字体，看字重与授权 2复制字体页「使用」区的代码放进 <head> 3在 CSS 里写 font-family: "wenfeng-{slug}" 4上线前创建项目、绑定域名、子集化减体积

CDN 地址规则

每款字体的每个字重是一份独立 CSS，地址由字体族 slug 与字重名组成：

https://cn.windfonts.com/wenfeng/fonts/{slug}/{weight}/web/index.css
  • {slug}：字体族标识去掉 wenfeng- 前缀，如 wenfeng-albbpht → albbpht。字体页「使用」区直接给出完整地址。
  • {weight}：小写字重名，regular bold light medium heavy…以字体页列出的字重为准，见对照表。
  • 文件名 index.css 为完整字集；zh_index.css 为中文子集，体积更小，见子集化。

CSS 内部按 Unicode 区间切成多个 woff2 分片，浏览器只下载页面实际用到的分片；字体文件与 CSS 同目录，跨域头已放开。

用 <link> 引入

放入页面 <head>。先 preconnect 再拉 CSS，可省一次 DNS + TLS 往返。免费提供的字体请保留授权标注注释。

<!-- 此中文网页字体由文风字体（Windfonts）免费提供，您可以自由引用，请务必保留此授权许可标注 https://wenfeng.org/license -->
<link rel="preconnect" href="https://cn.windfonts.com" crossorigin>
<link rel="stylesheet" href="https://cn.windfonts.com/wenfeng/fonts/albbpht/regular/web/index.css">

需要多个字重就多写几行 <link>，每个字重一份 CSS；字体页「使用」区与选字袋可一次生成多款、多字重的合并代码。

用 @import 引入

写在 CSS 文件顶部（@import 必须位于其他规则之前）。相比 <link> 会晚一个解析阶段，首屏字体优先用 <link>。

@import url('https://cn.windfonts.com/wenfeng/fonts/ibmps/regular/web/index.css');
@import url('https://cn.windfonts.com/wenfeng/fonts/ibmps/bold/web/index.css');

在 CSS 中使用

CSS 声明的 font-family 与字体族标识一致，为 wenfeng-{slug}。始终保留系统中文回退，避免加载期间空白。

.title {
  font-family: "wenfeng-albbpht",
               "PingFang SC", "Microsoft YaHei", sans-serif;
  font-weight: 400;
}

同一页面同时引入一款字体的多个字重时，请在 font-weight 上区分；如果你自己拼接 CSS，需要为每个字重的 @font-face 补上对应 font-weight，否则后加载的字重会覆盖前者。项目 CDN 生成的 CSS 已处理好这一点。

npm 与框架

现代前端工作流用 loader 按需注入，并拿到加载状态（loading / loaded / error）。

npm install @windfonts/loader

import { loadFonts } from '@windfonts/loader';

const status = await loadFonts([
  { family: 'wenfeng-albbpht', weights: ['regular', 'bold'], version: 'zh' }
], { display: 'swap' });

React 用 useWindfonts()，Vue 用 useWindfonts() composable，返回同一份状态对象。WordPress 站点可直接用文派的字体插件，在后台选字即可。

子集化

中文字体整包常在 5–15 MB。子集化只保留会出现的字，体积可减少 90% 以上。

方式适用在哪里
预制 · 完整 index.css正文内容不固定、需要生僻字公开 CDN
预制 · 中文 zh_index.css常见中文内容，去掉了大量扩展区字符公开 CDN
按文字标题、品牌名、固定文案；体积以 KB 计控制台 · 子集化工作台
按常用字 3500 / 7000正文不固定但不需要生僻字的站点控制台 · 子集化工作台
按编码范围多语言、自定义字集控制台 · 子集化工作台
 
https://cn.windfonts.com/wenfeng/fonts/albbpht/regular/web/zh_index.css

控制台生成的自定义子集作为项目版本发布，走项目 CDN 地址，改子集不需要改嵌入代码。

font-display

控制字体加载期间文字如何呈现。CDN 的 CSS 默认 swap；项目设置里可统一指定，项目 CDN 会按设置生成。

  • swap（默认）：先用回退字体显示，加载完成后替换。首屏最快，有一次重排。
  • block：短暂隐藏文字等待字体，适合品牌标题。
  • fallback / optional：网络慢时放弃替换，保证阅读稳定。

preload 与 preconnect

关键字体（首屏标题）可在 <head> 顶部预加载 CSS，再由 CSS 拉字体分片；配合 preconnect 效果最好。不要 preload 字体文件本身——分片由 unicode-range 决定，浏览器比你更清楚要哪几片。

<link rel="preconnect" href="https://cn.windfonts.com" crossorigin>
<link rel="preload" as="style" href="https://cn.windfonts.com/wenfeng/fonts/albbpht/bold/web/index.css">
<link rel="stylesheet" href="https://cn.windfonts.com/wenfeng/fonts/albbpht/bold/web/index.css">

缓存与更新

字体分片文件名含内容哈希，可长期缓存；CSS 短缓存（约 10 分钟），字体更新版本时只需 CSS 刷新。项目 CDN 地址指向项目「当前版本」，发布或回滚后 CSS 自动切换，无需改代码。

项目与项目 CDN

项目是「一组字体 + 一组域名 + 一份设置」的发布单元。登录控制台新建项目，从字体库或选字袋把字体加进来，逐款设定字重与子集，发布后得到项目地址：

https://cn.windfonts.com/p/{project-slug}/index.css
  • 一份 CSS 包含项目内全部字体与字重，已按项目设置处理 font-display 与 font-weight。
  • 免费版 1 个项目 / 3 个域名；专业版 10 个项目、域名不限、月流量 200 GB，见定价。

域名白名单

项目绑定的域名决定字体文件对谁返回。白名单外的请求会被拒绝，并记入控制台「域名 › 未授权访问」。

  • 支持精确域名与通配 *.example.com（不含根域名）；localhost 与 127.0.0.1 默认允许。
  • 新增域名需验证，两种方式任选：DNS TXT _windfonts.example.com → "windfonts={project-id}"，或在站点根目录放置 /.well-known/windfonts-verify.txt，内容为项目 ID。
  • 公开 CDN（cn.windfonts.com）不校验域名，但有限流；正式站点请走项目 CDN。

版本与回滚

项目每次改动（增删字体、修改子集、切换字重）都生成一个新版本，记录体积与说明；嵌入代码指向项目而不是具体版本，发布即生效。出问题时在项目「版本」标签回滚——回滚以旧版内容生成新版本，历史不丢。

用量与统计

控制台「用量」按项目、字体、字重、域名四个维度统计请求数与流量，另有成功下发、缓存命中、被拒三类占比，以及字体加载中位时间（仅白名单域名）。数据延迟约 5 分钟，支持 7 / 30 / 90 天与 CSV 导出。点任一字体可看各字重用量，便于从项目里移除很少用到的字重。

上传自有字体

支持 .ttf .otf .woff .woff2。上传时自动解析名称、字重、字符数，生成分片与全部格式，之后与库内字体一样加入项目、子集化。你必须拥有该字体的合法授权，上传即视为承诺；自有字体只通过项目 CDN 分发，不进入公开字体库。约定见上传条款。

选字袋

在字体库或字体页「加入选字袋」，到选字袋统一预览、比较，并一次生成多款字体的合并嵌入代码。登录后可把选字袋整体添加到某个项目。选字袋存在浏览器本地。

许可与注意

  • 本站转述条款，不二次授权。每款字的范围以字体页「授权」区的出处为准；没有原文链接的不要当成已经核实。
  • 「素材站声明」不是厂商官网。千图、包图、字魂等平台上的「可商用」须再核权利人。
  • 归属看品牌方。字库代做的字，版权在出资的品牌，不能拿制作方其他款的许可来猜。
  • 派生、地区版会标上游和同系。写明沿用上游许可的，仍须改名并保留声明；未写明的不要自行推断。
  • 免费商用或开源字体请保留版权与授权标注注释；不得单独分发字体文件、不得二次托管 CDN 分片。
  • 公开 CDN 有限流与突发保护；正式站点请创建项目并绑定域名，走项目 CDN 地址。

许可类型

字体按许可短名区分，不能把全部「免费商用」当成一种许可。

  • 宽松（OFL、Apache、MIT）：多数商业项目可用。OFL 允许改字再分发，但必须换名字、保留声明，不得单独卖字体文件。
  • 署名（CC BY）：可商用，须按许可署名原作者。
  • 相同方式共享（CC BY-SA）：署名之外，衍生作品须用同一许可。
  • 禁止改作（CC BY-ND）：可传播原件，不得分发改过的版本。
  • Copyleft（GPL）：再分发须遵守 GPL，不能当 MIT 用。
  • 素材站 / 作者声明 / 未标明：只有档位或口头声明，没有可核验原文。上线前自己找权利人。

选字袋里多款字体混装时，按字核对出处，不要合成一张「均可商用」。

常见问题

页面上字体没生效？
检查三件事：CSS 能否打开；font-family 是否与 CSS 内声明一致（wenfeng-{slug}）；所用字重是否在该字体的字重列表里。
控制台里请求量很低，但站点访问不少？
正常——分片文件会长期缓存，回访用户走浏览器缓存就不会再请求；缓存命中占比高说明工作正常。
为什么字体打不开？
来源不在白名单。「域名」页会列出这些来源，是自己的站点就加上，别人的保持拦截即可。
能把字体文件下载到自己服务器吗？
免费商用字体请到 wenfeng.org 下载原始文件自行部署；CDN 分片文件不用于二次托管。
去字体库挑一款 打开控制台 有错漏？在 GitHub 提 issue 或写信 docs@windfonts.com
