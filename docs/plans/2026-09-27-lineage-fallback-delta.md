# 谱系缺字补全 · 按字集差集挑源（拍板）

对照：`2026-09-24-font-mix-subset-fallback.md` §3 / §6。  
拍板：Feng · **2026-09-27**。

---

## 一句话

缺字补全**不要默认指向上游**。按目录里能算的字集差集，自动挑「比当前款多字」的谱系邻居；**优先直接下游**（fork / locale 子款），其次才是直接上游，再次同 group 兄弟。CSS 机制不变：主 family 在前 + `fallback=` 只出缺口 face。与 `localeFallback`（简繁兄弟）分开。真造字仍走 wenfeng.org。

---

## 为什么改

旧拍板「默认直接上游」在思源这类源头上会**藏住补全勾选**（源头没有上游），或把字更多的子款（更纱等宽、昭源黑体等）晾在一边。派生款若已经比上游字多，再建议贫瘠上游也没意义。

---

## 算法（说人话）

1. **候选池**（跳过自己、无 `family`、任一侧 `citeAllowed` 不放行）  
   - **直接下游**：目录里 `lineage.upstreamName` 经 `findFontByName` 对准本款的字体  
   - **直接上游**：本款 `upstreamName` 能在目录解析到  
   - **同 group 兄弟**（可选垫底）：同 `lineage.group`、且不是上两类

2. **覆盖分**：优先用 `charCount`，否则 `glyphCount`。任一侧计数 **≤ 1 当未知**——未知不参与「正向差集」排名（该候选直接丢掉）。

3. **差集**：`delta = 候选字数 − 本款字数`。只留 **`delta > 0`**（门槛约 50，滤噪声）。

4. **排序**：在正向候选里，角色优先 **直接下游 > 上游 > 兄弟**；同角色比 **delta 更大**。

5. **结果**：没有合格候选 → 不画谱系补全勾选；有则返回 `{ font, role, delta, label }`，文案「用「某某」补缺字」，提示「约多 N 字 · 同字重 · 仅缺口」。

---

## 不改什么

| 项 | 态度 |
|---|---|
| `fallback=` unicode-range 缺口裁切 | 照旧 |
| `localeFallback` 简繁勾选 | 独立；同时开仍优先谱系 |
| 真造字 / 虚拟挂轮廓 | 不做进 CDN；造字走 wenfeng.org |
| 默认自动打开勾选 | 仍默认关，用户显式勾 |
