# 控制台 V1 完成标准 · 2026-09-27

对照 [CONSOLE.md](../CONSOLE.md)。**按身份分三套侧栏**；运营字典不进本仓。

## 算完成

| 角色 | 必须能独立做完 |
|---|---|
| 嵌字客户 | vault 登录 → 建项目 → 加公开字 → 域名验证 → 发布 `/p/` → 用量见请求/403 |
| 持证客户 | 上传证书 → 审核通知 → 账号 CSS 或 `source=cert` 进项目发布 |
| 认领方 | 提交认领 → 通过后进厂商台，改「我的页」并发布公开资料 |
| 管理员 | 登录后见完整侧栏；审核字典仍走 vault `/admin` |

## 不算 V1

子集真切包、支付下单、WP 统一登录、运营字典迁入 app、全站无障碍走查。

## 侧栏（按身份）

| 身份 | 一级 |
|---|---|
| 客户 | 概览 · 项目 · 证书 · 设置 |
| 厂商（有 approved 认领） | 概览 · 我的页 · 我的字体 · 上传 · 证书 · 项目 · 设置 |
| 管理员 | 概览 · 项目 · 域名 · 我的字体 · 子集化 · 用量 · 证书 · 团队 · 设置（+ 有认领时我的页） |

**降级（URL 仍可开）：** 客户看不到的项深链仍可用；通知在设置/页脚。
