# 目录与页面文案规范（字体介绍 / 厂商介绍）

> 详情页写**字体**，厂商页写**厂商或品牌**。二者不互相顶替。授权、证据链、服务状态仍在详情「授权」区，不进简介。  
> 本文件是后续不定期修正的**记录真源**；改 `description` / `foundries.json` 时同步更新 `data/catalog-copy-manifest.json`。

## 1. 分工

| 位置 | 写什么 | 不写什么 |
|---|---|---|
| **字体详情 · 简介**（侧栏默认展示 `font.description`） | 这款字是什么、谁发布、适合什么场景、1～2 句风格 | 长篇营销、流水线批次号、许可全文、与别款纠缠（除非 RFN/易混名一句点清） |
| **字体详情 · 授权** | 档位、出处与依据（证据链） | 重复简介里的合作故事 |
| **字体详情 · 厂商简介**（侧栏折叠，默认收起） | 与 `foundries.json` 一致，可多段 | 单款字的字形描述、嵌入参数 |
| **厂商页 · 简介** | 机构/作者/项目是谁、代表作方向、官网 | 单款字的字形描述、嵌入参数 |
| **`foundries.json` · description** | 与厂商页一致，可略短 | 「出品的字体」占位句 |

## 1.1 长短字段（详情侧栏）

| 字段 | 用途 |
|---|---|
| `description` / `foundries.json` · `description` | **全文存档**（导出、厂商页、检索；详情侧栏不整段贴出） |
| `descriptionBrief`（可选） | 详情侧栏展示；缺省时前端按字数截断（字体约 120 字、厂商约 72 字 / 一句） |
| 详情 · 字体简介 | 默认**展开**，只显示 `descriptionBrief` 或截断句 |
| 详情 · 厂商 / 品牌 | **折叠**，内文一句 +「查看更多」→ 厂商页 |

改文案时：全文写进 `description`，侧栏句写进 `descriptionBrief`（或依赖截断）；同步 `catalog-copy-manifest.json`。

## 2. 字体简介模板（目标形态）

按顺序写 **2～4 句**，每句只干一件事：

1. **定名 + 发布方**：「{中文名}，{品牌/作者} {年份} 发布。」
2. **风格 + 用途**：「{无衬线/宋体…}，笔画…，适合 {标题/正文/屏显}。」
3. **字重/语言（若有）**：「含 {N} 个字重；覆盖 {简/繁/日}。」
4. **易混名（可选）**：「与 {旧名/别款} 不同款；授权见本页。」

禁止：

- `OSS ingest batch*`、`lineage-stub` 等内部版本串进用户可见 `description`
- 英文缩写堆砌（L/R/M）— 用中文或全字重名
- 把 vault 导出长段 SEO 原样贴入

---

## 3. 厂商简介模板

1. **是谁**：{中文名}（{kind：作者/字库/品牌/开源项目/素材平台}）
2. **做什么**：{代表字体方向，1 句}
3. **与本站关系**：在库 {N} 款（由列表统计，不写死）
4. **外链**：官网 / GitHub（有则写，无则省略）

素材平台（`kind=platform`）须带一句：「站内展示素材站声明，商用以权利人页面为准。」

## 4. 核对态对外用词（与证据链一致，详情折叠外少用）

| 对内字段 | 对用户 |
|---|---|
| 原文核对 | 已核对协议原文 |
| 标准许可 | 已核对标准开源许可 |
| 出处核对 | 已核对许可出处 |
| 无 | 尚未核对 |

档位（筛选/ chip）：开源商用、免费商用、需授权、个人免费、待核实。

**文风云®**：文风字体的商业云服务名称；服务状态行保留，与「文风字体」站点品牌并存。

- 只改 `data/fonts-by-slug/*.json` + `data/fonts-detail.json` + `foundries.json` 时，跑现有目录合并脚本，**不要**手改 `fonts.json` 大块。

- 与 vault 不一致时，以 vault 为准重导；改 vault 前先备份（见 HANDOFF）。
