# 文风控制台 · 三套工作台

2026-09-27。顾客用的是本仓 `app/`（正式挂 `app.windfonts.com` OSS）。**字典 / 认领审核 / 同步**仍在 `vault.windfonts.com/admin`（仓 `fonts-vault`）。域名总则见 [DOMAIN-ARCHITECTURE.md](DOMAIN-ARCHITECTURE.md)；认领能改什么，以 [CLAIM-SCOPES.md](CLAIM-SCOPES.md) 为准。

「三套」按**登录身份**进不同侧栏，不是顶部分段开关来回切：

| 身份 | 怎么判定 | 进哪一套 |
|---|---|---|
| **客户 / 普通用户** | `role=user` 且无 `approved` 认领 | 嵌字瘦版（刚收口的 V1） |
| **厂商 / 作者** | 有至少一条 `approved` 认领 | 品牌与字体管理台 |
| **管理员** | `role=admin` 或 `owner` | 收口前完整侧栏 |

运营字典后台仍是 vault `/admin`，不并进顾客 `app/`。

## 客户（嵌字瘦版）

主路径：登录 → 项目 → 加字 → 域名 → 发布 `/p/` → 看用量。

侧栏一级：**概览 · 项目 · 证书 · 设置**。

降级深链仍可开：域名总表、子集化、用量、团队、收藏；通知在设置与侧栏页脚。

## 厂商（品牌 / 字体）

认领通过后侧栏变为：**概览 · 我的页 · 我的字体 · 上传 · 证书 · 项目 · 设置**。

- **我的页**：介绍、官网、外链（及作者/开源仓库）；不改许可档位  
- **我的字体 / 上传**：维护自家字与授权上传  
- **项目**：若同时要嵌字，仍可用

侧栏启动时拉 `/api/claims`；有通过项即切到厂商台。本机 mock 示例「阿里巴巴设计」只为看入口。

## 管理员（完整侧栏）

侧栏恢复收口前完整项：**概览 · 项目 · 域名 · 我的字体 · 子集化 · 用量 · 证书 · 团队 · 设置**；若另有认领，设置前再插 **我的页**。

字典、分类、同步、认领审核、域名黑白名单仍去 vault `/admin`。

## 入口

| 人 | 从哪进 | 看见 |
|---|---|---|
| 要嵌字体的人 | 登录 → 客户台 | 瘦侧栏 + 项目闭环 |
| 作者或厂商 | 认领通过后刷新控制台 | 厂商台（页 / 字体 / 上传） |
| 文风管理员 | 登录（admin）→ 完整侧栏；审核去 vault | 完整 app + `/admin` |
| 免费 / 专业 | 同一客户台 | 专业才开上传前缀等 |

## 证书开引用（cite-closed）

吉利黑体等带 `cite-closed` 的款：默认不开公共 CDN。用户上传证书 → `/admin/font-certs` 审核通过后，可用账号级 CSS 或项目 `source=cert` 发布。**不会**灌 `fonts-packages`。

## 功能门禁（身份 × 套餐）

| 能力 | 客户免费 | 客户专业 | 厂商（approved） | 管理员 |
|---|---|---|---|---|
| 项目嵌字 / 证书 | ✓ | ✓ | ✓ | ✓ |
| 上传自有字 | — | ✓ | ✓ | ✓ |
| 我的页 / 归属字列表 | — | — | ✓ | 有认领时 ✓ |
| 字体名前缀 | — | ✓ | — | ✓ |
| 域名总表 / 子集 / 用量 / 团队一级 | — | — | — | ✓ |
| vault 运营后台 | — | — | — | 脚栏入口 |

运行时：`WFApp.can('upload'|'pages'|'fontPrefix'|…)`。

## 配额与通知

- `GET /api/plan`：当前档 + 用量只读（支付未通，**不强制**免费上限）。
- `GET/POST /api/notifications`：证书 / 认领审核站内信；设置与侧栏页脚入口。

完成标准见 [plans/console-v1-definition.md](plans/console-v1-definition.md)。
