# 文风控制台 · 三套工作台

2026-09-24。顾客用的是本仓 `app/`。运营不在这里，在现网 `app.windfonts.com/admin`（仓 `fonts-vault`）。认领能改什么，以 [CLAIM-SCOPES.md](CLAIM-SCOPES.md) 为准。

一个账号可以同时用字、又维护已认领的页。侧栏上方切换「用字 / 我的页」。没有通过的认领时，不出现第二个入口。

## 用字

把字体嵌到自己的网站上。免费和付费是同一套菜单，差别只在套餐开不开某些项。

侧栏：概览、项目、域名、我的字体、子集化、用量、团队、设置。

团队里的所有者、编辑、只读，是这一个客户账号里的分工，不是作者或厂商身份。

设置里有：账号、套餐（开发模式才显示价格）、新项目默认、API 密钥、这个账号的审计。认领表单不在这里，到公开 [claim.html](../claim.html)。恢复示例数据只在本机开发时出现。

付费（`plan.id = pro`）才打开的：

- 上传自有授权字
- 项目嵌入里的字体名前缀

免费档仍可看这些行，不能改。配额以定价页为准：免费 1 个项目、3 个域名、10 GB；专业 10 个项目、域名不限、200 GB。

## 我的页

认领状态是 `approved` 之后才有。作者、字库、品牌方、开源项目、素材平台共用这一台，不按身份再拆登录。

能改的只有本页资料：介绍、官网、外链；作者和开源项目还可以填仓库。不能改许可档位，不能改「已核对」，不能看见别人的项目和用量。

这些修改先记在账号里。公开厂商页要等发布接口接上才变。

## 运营

字体、厂商字典、分类、风格、同步、安全开关、域名黑白名单、认领审核、运营审计，留在现网 admin。本仓控制台不放这些菜单。

## 入口

| 人 | 从哪进 | 看见 |
|---|---|---|
| 要嵌字体的人 | 登录 → 用字 | 项目和嵌入 |
| 免费 / 专业 | 同一用字台 | 专业才开上传和字体名前缀 |
| 作者或厂商 | 公开认领页提交；通过后侧栏多「我的页」 | 自己的页 |
| 文风运营 | `app.windfonts.com/admin` | 字典和审核 |

示例数据里有一条已通过的「阿里巴巴设计」页，只为看切换，不表示该页已由本站认领。`foundries.json` 的 `claimed` 不因此改成 true。
