常见问题

嵌入、字重、白名单与授权。点开一条看说明；接入步骤见文档。

页面上字体没生效？

按顺序查三件事：

  1. CSS 地址能否打开（浏览器网络面板应为 200）。优先用字体页「使用」区复制的地址（动态 /api/css 或拆包 fonts-packages/…/result.css）。
  2. font-family 写成 "wenfeng-{slug}"（如 wenfeng-albbpht）。包内可能声明 windfonts-*，页面上两种都写更稳。
  3. 字重是否在该字体字重列表里；CSS 里的 font-weight 要与引入的那一档对应。

更完整的规则见CDN 地址与CSS 用法。

粗细看起来不对，或 Bold 和 Regular 一样？

常见原因：

  • 本机装了同名字体，CDN CSS 里的 local() 抢先命中了本机 Regular。本站预览会剥掉 local()；自己拼 CSS 时也请只保留 url()。
  • 同一页多个字重却没给每个 @font-face 写清 font-weight，后加载的会盖住前面的。
  • 个别款目录写 Regular，包内实际是 ExtraLight / Bold 等——以字体页样张为准，并报给我们重拆。
动态、拆包、静态有什么区别？
  • 动态：字体页默认嵌入，cn.windfonts.com/api/css?family=…&weight=…&subset=…（可切 hk / en）。
  • 拆包：本站预览真源，…/fonts-packages/{Normalized}/{Weight}/{full|zh-common}/result.css，与动态读同一批对象。
  • 静态：旧路径 /wenfeng/fonts/{slug}/{weight}/web/，多数已停更，仅兼容。

完整规则见CDN 地址；字体页「使用」区可切换形态与节点。

控制台请求量很低，但站点访问不少？

正常。分片文件名带内容哈希，可长期缓存；回访走浏览器缓存就不会再打到 CDN。缓存命中高，说明工作正常。用量口径见用量与统计。

为什么字体打不开 / 返回被拒？

若走的是项目 CDN（/p/{slug}/），来源域名必须在白名单里。控制台「域名」页会列出被拒来源：是自己的站点就加上并完成验证，别人的保持拦截。公开 CDN 不校验域名，但有限流。详见域名白名单。

能把字体文件下载到自己服务器吗？

免费商用或开源款，请到 wenfeng.org 取原始文件自行部署。CDN 分片（woff2）不用于二次托管或单独分发。

「免费商用」是不是都能随便用？

不能打包理解。每款字的范围以字体页「授权」区的出处为准；素材站声明不等于厂商官网。本站不二次授权。类型对照见许可类型，注意边界见免责。

厂商页上的「归属」「受托」「同系」是什么意思？
  • 归属：版权在本页这家（品牌方或字库）。
  • 受托：这家代做，版权在出资的品牌方，不计入本页归属。
  • 同系：地区版或同规格，链到字体库同系筛选。
  • 开发视图另有顶栏「开源派生」「思源派生」，以及列表里的「派生至」。设计视图不显示。口语「二创」同义，不是旁类。勿写「改自」。
子集化在哪里做？公开 CSS 已经很小了吗？

公开包按 Unicode 区间切分，浏览器只拉用到的片。还要再瘦，用控制台「子集化」按文字 / 常用字 / 编码范围生成，并发布到项目。说明见子集化。
